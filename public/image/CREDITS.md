# Sample image credits

The files in this directory are derived from the same NASA material as the sample
media, committed only so the documentation site and the browser test suite render
real photographs without a network request. The registry items never ship these
files.

The source, its provenance and the licensing are described in
[`../media/CREDITS.md`](../media/CREDITS.md): stills from _Around the Moon for All
Humanity: Artemis II (Official Launch Trailer)_, NASA, used under the
[NASA Images and Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).
Blocove is not affiliated with, sponsored by or endorsed by NASA.

## Files

All files are generated by [`scripts/generate-image-samples.mjs`](../../scripts/generate-image-samples.mjs)
from two committed sources: `public/media/sample-poster.jpg` and
`public/media/sample-video.mp4`.

| File                    | Source                                  | Change                                               |
| ----------------------- | --------------------------------------- | ---------------------------------------------------- |
| `sample-launch-320.jpg` | `sample-poster.jpg`                     | Scaled to 320×180, JPEG quality 4.                   |
| `sample-launch-480.jpg` | `sample-poster.jpg`                     | Scaled to 480×270, JPEG quality 4.                   |
| `sample-launch-640.jpg` | `sample-poster.jpg`                     | Scaled to 640×360, JPEG quality 4.                   |
| `sample-launch-960.jpg` | `sample-poster.jpg`                     | Left at 960×540, JPEG quality 4.                     |
| `sample-frame-a.jpg`    | `sample-video.mp4`, frame at 00:00:01   | Scaled to 960×540, JPEG quality 4.                   |
| `sample-frame-b.jpg`    | `sample-video.mp4`, frame at 00:00:03.5 | Scaled to 960×540, JPEG quality 4.                   |
| `sample-frame-c.jpg`    | `sample-video.mp4`, frame at 00:00:06   | Scaled to 960×540, JPEG quality 4.                   |
| `sample-before-960.jpg` | `sample-poster.jpg`                     | Desaturated, then scaled to 960×540, JPEG quality 4. |
| `sample-after-960.jpg`  | `sample-poster.jpg`                     | Scaled to 960×540, JPEG quality 4.                   |

## Regenerating

```bash
node scripts/generate-image-samples.mjs
```

The script requires `ffmpeg` and reads only committed files.
